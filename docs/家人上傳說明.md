# 作品照片怎麼放（給店主的一頁說明）

你只要做一件事：**用手機把照片放進 Google 雲端硬碟的「作品資料夾」**，網站會自己更新。

---

## 資料夾長這樣

```
彩蝶美甲/美睫 作品集（總資料夾）
├─ 美甲/                 ← 第一層 = 網站上的「類別」
│   ├─ 01_簡約裸色_純粹耐看/   ← 第二層 = 「相簿」（可以不建，直接放照片也行）
│   ├─ 02_法式/
│   └─ IMG_1234.jpg      ← 直接放在類別裡的照片，會歸在「全部作品」（有其他相簿時叫「未分類」）
├─ 美睫/
├─ _首頁主圖/             ← 想放在首頁大圖的照片放這裡（可以放好幾張，會輪播）
└─ _草稿/                 ← 底線開頭的資料夾網站不會顯示，可以當草稿區
```

## 命名小規則（只影響顯示順序和標題）

- 資料夾名稱開頭的數字是**排序用**，網站上看不到：`01_簡約裸色` 會顯示成「簡約裸色」。
- 數字後面用 `_`、`-`、`.` 或空格隔開都可以：`2-法式`、`03 節慶彩繪` 都行。
- 名稱後面再加一個 `_` 可以加副標：`01_簡約裸色_純粹耐看` → 標題「簡約裸色」、副標「純粹耐看」。
- 沒有數字的資料夾會排在有數字的後面。
- 名稱以 `_` 開頭的資料夾（例如 `_草稿`）**不會出現在網站**，唯一例外是 `_首頁主圖`。
- 想指定某張當相簿封面：把那張照片改名成 `cover`（例如 `cover.jpg`）。沒有的話用最新的一張。

## 什麼會顯示、什麼不會

| 放進去的東西 | 網站 |
|---|---|
| JPG、PNG、HEIC（iPhone 原始格式）、WebP | ✅ 顯示 |
| 影片、文字檔、PDF | ❌ 不顯示（放了也沒關係） |
| 空的資料夾 | ❌ 不顯示 |
| 資料夾裡再開資料夾（第三層） | ❌ 不顯示 |
| 直接放在總資料夾底下的照片 | ❌ 不顯示，請放進類別 |

## 更新多快？

- **新增／刪除照片**：客人重新整理網頁，幾秒內就會看到。網頁開著不動，大約一分鐘內自動出現。
- **新增或改名資料夾**：一樣自動，不用找任何人改程式。
- 剛上傳的照片前幾分鐘是由 Google 直接提供（會比較大張、慢一點），約 5～10 分鐘後網站會自動整理成快速版。iPhone 的 HEIC 照片也一樣可以。

## 請注意

- 總資料夾是「知道連結的人都能看」，**只放要給客人看的成品照**，不要放客人的臉、個資或其他私人照片。
- 照片會自動去除定位資訊（GPS）後才放上網站。
- 檔名不會顯示在網站上，手機隨便命名沒關係。
- 想暫時下架一張照片：搬到 `_草稿` 或直接刪除，網站會立刻跟著消失。
